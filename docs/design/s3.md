# Object storage

**A bucket is a type, a key is a plain string, and the module does no HTTP or TLS of its own.**

**Guide:** [Object storage](../guide/s3.md) · **Reference:** [`nilo_s3`](../reference/s3.md#nilo_s3)

The code is `s3/s3.zig` (`open`), `s3/store.zig` (the Store, credentials, signing key), `s3/bucket.zig` (`Bucket(name, opts)` and its calls), `s3/sign.zig` (SigV4), `s3/listing.zig` (the `list` XML), and `s3/canned.zig` / `s3/live.zig` (the two ways it is tested).

## Overview

```
  s3.open(gpa, .{ endpoint, region, credentials })  ──►  Store
       one connection pool, one derived signing key,          │
       refreshed lazily against .expires_at                   │
                                                                ▼
  s3.Bucket("avatars", .{ .max_bytes, .sse, .style })  ──►  Avatars.open(&store)
       a type: name, addressing, ceilings settled                │
       while compiling, a constant SignedHeaders                 │
                                                                   ▼
                                              get / getRange / getIf / stream
                                              put / putStream / delete / head
                                              list (one page, no follow)
                                              presign / presignPost
                                                                   │
                                                                   ▼
                                                        nilo_fetch (std.http.Client
                                                        plus the gate, the deadline,
                                                        the bounded drain)
```

Everything above the last arrow is this module: signing, the bucket, and the types a caller gets back. Everything below it belongs to `nilo_fetch`, which is why `nilo_s3` adds no packages to `build.zig.zon`.

## Rules

1. **A bucket is a type, not a string.** `s3.Bucket(name, opts)` returns a type, so two buckets are two Services, and a handler picks the one it wants by argument type; it cannot reach the wrong one. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
2. **A key is deliberately not a type.** It is a plain run-time string, percent-encoded once per RFC 3986 with `/` left alone. nilo never invents, normalises or validates a key, so a key built from user input is the caller's own path-traversal risk to handle. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
3. **What is fixed at compile time is what belongs to the bucket, not the deployment**: name, addressing style, `max_bytes`, `sse`, `presign_max`. Endpoint, region and credentials stay run-time, because `nilo_config` is what lets development and production use the same binary. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
4. **The set of headers SigV4 signs is a fixed list known at compile time**, so `SignedHeaders` is a constant and signing never sorts anything per request. Arbitrary `x-amz-meta-*` headers are rejected, partly for that reason and partly because a metadata value could otherwise inject a header into the request being signed. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
5. **The HTTP underneath is `nilo_fetch`, which is `std.http.Client` with rules in front, and this module adds no dependency to `build.zig.zon`.** The two expensive parts of a client, TLS and a connection pool, are where the bugs and the memory are; framing (the part nilo's own HTTP code could have shared) is only a fifth of the work. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md), [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md)
6. **The concurrency limit, the deadline and the bounded drain live in `nilo_fetch`, not here**, because `nilo_s3` is a user of the Fitting, not the owner of an HTTP client. Adding this second user cost that layer one new type (`fetch.Exchange`, for a body too large to hold) and nothing else. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md), [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md)
7. **A `503 SlowDown` or a 5xx is returned as `error.Throttled` or `error.Unavailable`, not retried**, so a handler can shed load or answer from a cache instead of a fiber sleeping while holding a permit. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md)
8. **The signing key is derived once a day and cached**, not recomputed per request. Region and service are fixed at `open()` and the date changes daily, so signing costs one HMAC-SHA256 over the string to sign instead of five. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
9. **Credentials are refreshed lazily, by the request that notices they are close to `expires_at`**, with no background task; `.static` is the same mechanism with no expiry. A failed `.fetch` fails nobody while the old key is still valid, and is tried again five seconds later; one fiber refreshes while the others sign. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
10. **The payload hash is `UNSIGNED-PAYLOAD` over `https://` and a real SHA-256 over `http://`**, decided only by the endpoint's scheme. Over TLS the hash adds nothing TLS does not already provide, and hashing a large body costs real CPU on the fiber. A streamed `put` is always unsigned, because hashing data not yet read would mean reading it twice. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
11. **`getIf` returns a union, not an error**: `.unmodified` is a 304 and a success, never something the caller has to catch. [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md)
12. **A presigned URL lasts `min(requested, presign_max, credential life)`**, and `Presigned`/`Posted` return the real `expires_at`, because a URL signed with temporary credentials stops working when they expire, whatever `X-Amz-Expires` says. [ADR 060](../adr/060-a-signing-key-changes-once-a-day.md)
13. **`list` returns one page and does not follow the cursor itself.** It is limited by `max_keys` and the fixed maximum of 1,000; asking for more is `error.Rejected`, not silently reduced. The cursor comes back as text for the caller's own loop. There is no `listAll`. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md)
14. **A browser uploads to the bucket through `presignPost`, a signed POST policy**, not a presigned link. The policy's `.max_bytes` defaults to the bucket's own limit and is capped at it, never raised above it, because a browser upload is the one way an object could exceed that limit without nilo seeing a byte. [ADR 112](../adr/112-a-browser-uploads-with-a-form-rather-than-a-link.md)
15. **`s3.Options.public_endpoint` is the host a browser reaches, when it differs from the host this process connects to.** `presign` signs for that host and `presignPost` posts to it; every call that connects (`get`, `put`, `head`, `delete`) still connects to and signs for the process's own endpoint. Rewriting a URL's host after signing is not supported, because the host is part of the signature. [ADR 177](../adr/177-a-presigned-url-names-the-host-the-browser-reaches.md)

## Open questions

- **`LIST` that follows its own cursor and `COPY` are not built.** Both are where "bytes at a key" ends and a document format begins; multipart upload was the third until a caller arrived and `putMultipart` shipped as one call owning the protocol whole. [ADR 058](../adr/058-most-of-an-s3-client-is-not-s3.md) and [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md) give the reasons, and `docs/roadmap.md` is where someone who needs `COPY` should start.
- **The binary size of a program that imports `nilo_s3` has not been measured.** [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md) says the two test programs for the stripped `ReleaseFast` comparison are written but not run.
- **The stack cost of a suspended `get` at its highest point has not been measured.** [ADR 063](../adr/063-an-object-store-is-a-service-that-dials.md) gives the added idle-connection cost as 0 bytes but flags that number as not yet measured.
- **Arbitrary object metadata is rejected for a performance reason nobody has re-measured.** [ADR 059](../adr/059-a-bucket-is-a-type-and-a-key-is-not.md) says it can be reconsidered by whoever measures the cost of sorting `SignedHeaders` per request.
